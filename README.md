# Chordify

演奏体験の価値を高めるための iOS アプリ。

## コアバリュー

生成 AI の進化によって、音楽そのものを生み出すコストは限りなくゼロに近づいています。しかしそれは同時に、人が楽器を手にして音を出し、仲間と合わせて演奏するという「身体性を伴う体験」の価値を、相対的に押し上げていきます。

Chordify は、その体験に寄り添うアプリです。ステージ上でもスタジオでも、演奏者が音楽に集中できるよう、コード譜・歌詞・段取りをひとつにまとめて管理します。楽曲の「準備」と「本番」をシームレスにつなぐことで、演奏という行為そのものをより豊かにすることを目指しています。

## 概要

曲ごとに歌詞とコードダイアグラムをまとめて管理し、練習から本番まで一貫してサポートします。編集モードで歌詞を入力しながらコードを配置し、パフォーマンスモードでは自動スクロール表示で演奏に集中できます。横画面のテレプロンプターモードでは、セクションを左から右へ流れるレイアウトで大きく表示します。バンドメンバー間でのセットリスト共有（開発予定）を見据え、チームでの演奏体験全体を高めることを長期的なゴールとしています。

## 主な機能

### 曲一覧
- 曲の追加・削除（スワイプ削除 + 確認ダイアログ）
- タイトル・メモ（セットリスト名など）を横断した全文検索
- 任意のステータスラベル（練習中・本番OK など）を各曲に設定
- BPM・カポタストをチップ表示

### コードブック
- コードダイアグラムをライブラリとして登録・管理
- フォルダによるグループ分け（メジャー、マイナー、7th など）
- 基本的な 4 和音コード（23 種）をデフォルトで収録
- フレットボードエディタで 1〜25 フレットに対応したオリジナルコードの作成

### 曲設定
- タイトル・BPM・カポ・スクロール速度・テレプロンプタースクロール速度を個別設定
- メモ欄（セットリスト名の記入などに活用、検索対象）
- ステータスラベル（本番OK・要修正 など自由入力）

### 編集モード
- 歌詞をセクション単位で管理（1 セクション = 1 行）
- Return キーで次のセクションを作成（カーソル位置でテキストを分割、コード配置を引き継ぎ）
- コードエリアをタップしてコードを配置
- ドラッグでコードの横位置を微調整
- コードのダイアグラム表示・コード名表示を個別にオン / オフ
- 左スワイプでセクションを削除（確認ダイアログあり）
- エフェクターメモをセクションごとに記録

### パフォーマンスモード
- コンテンツ先頭は画面中央から開始（視認性向上）
- 設定した速度で自動スクロール
- 手動スクロールに対応（ドラッグ + フリックで慣性スクロール）
- コードの表示モードをタップで順番に切り替え（カスタム → ダイアグラムのみ → コード名のみ → 非表示）
- メトロノーム（クリック音）をオン / オフ
- コードダイアグラムをタップするとプレビューシートを表示

### テレプロンプターモード（横画面専用）
- 端末を横向きにすると自動で切り替わり、縦向きに戻ると終了
- セクションを列単位で横スクロール表示（コンテンツ先頭は画面中央から開始）
- 右サイドバーに操作ボタンを集約（再生/一時停止・コード表示切替・セクションメモ表示切替・マーカー追加・終了）
- 下部タイムラインバー：ドラッグでシーク、オレンジのマーカーを打ち込み・タップで削除
- セクションメモ：各セクションの下部にメモ欄を表示（タップで追加・編集）
- テレプロンプタースクロール速度はパフォーマンスモードと独立して設定可能

### フレットボードエディタ
- ギター指板を忠実に再現したビジュアルデザイン
- 横スクロールで 1〜25 フレットに対応
- 弦ごとにミュート (X)・開放弦 (O)・押弦を切り替え
- ローコード（G・A など）は 1 フレット目から自動表示

## 技術スタック

| 項目 | 内容 |
|------|------|
| プラットフォーム | iOS 17+ |
| UI フレームワーク | SwiftUI |
| データ永続化 | SwiftData |
| アーキテクチャ | MVVM（`@Observable` ScrollViewModel） |
| オーディオ | AVAudioEngine（合成クリック音、サイレントモード対応） |
| 言語 | Swift 5.9+ |

## プロジェクト構成

```
chordify/
├── Models/
│   ├── Song.swift              # 曲モデル（BPM・カポ・メモ・ステータス・表示モード）
│   ├── LyricsSection.swift     # セクション（歌詞・コード配置・セクションメモ）
│   ├── ChordDiagram.swift      # コードダイアグラム（グローバル / 曲固有）
│   ├── ChordFingering.swift    # フィンガリングデータ + effectiveFingering
│   ├── ChordPlacement.swift    # コード配置（正規化 X 座標・表示設定）
│   ├── EffectorMemo.swift      # エフェクターメモ（セクションに紐付く）
│   ├── StructEvent.swift       # 後方互換用（現在は LyricsSection.structLabel に移行）
│   └── DefaultChords.swift     # デフォルトコードのシードデータ
└── Views/
    ├── ChordBook/
    │   ├── ChordBookView.swift      # コードブック（グリッド表示・フォルダ別）
    │   └── ChordEditView.swift      # コード追加・編集フォーム
    ├── Songs/
    │   ├── SongListView.swift       # 曲一覧（検索・ステータスラベル）
    │   ├── SongDetailView.swift     # 曲詳細（編集 / パフォーマンスモード）
    │   ├── TeleprompterView.swift   # テレプロンプターモード（横画面）
    │   └── LyricsScrollView.swift   # 自動スクロール ViewModel
    └── Common/
        ├── FretBoardView.swift        # コードダイアグラム表示（Canvas）
        ├── FretBoardEditorView.swift  # コードダイアグラム編集
        ├── ChordPickerSheet.swift     # コード選択シート
        ├── ChordDiagramCell.swift     # コードセル（一覧用）
        └── EffectorMemoSheet.swift    # エフェクターメモシート
```

## 今後の追加予定機能

### オンライン曲共有（バンドメンバー間）
バンドメンバー同士でコード譜・歌詞・セクションメモを共有できる機能。セットリストを丸ごと同期することで、メンバー全員が同じ最新データで演奏に臨める状態を目指します。想定する実装技術：CloudKit / Firebase など。

### 音声ファイルアップロード
曲に音声ファイル（MP3・AAC など）を紐付けて、アプリ内で再生できる機能。オリジナル音源と歌詞・コードを一元管理し、コピー練習や音取りをよりスムーズに行えます。

### エフェクターメモの拡充
現在はテキスト入力のみのエフェクターメモを、ノブ・スイッチなどビジュアルなパラメータ入力に対応させる予定です。
