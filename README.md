# Chordify

ギタリスト向けのライブ・練習サポート iOS アプリ。コードダイアグラムと歌詞をセットで管理し、パフォーマンス中の自動スクロールやメトロノームで演奏をサポートします。

## 概要

Chordify は、曲ごとに歌詞とコードダイアグラムをまとめて管理できるアプリです。編集モードで歌詞を入力しながらコードを配置し、パフォーマンスモードでは自動スクロールするテレプロンプター的に使用します。

## 主な機能

### コードブック
- コードダイアグラムをライブラリとして登録・管理
- フォルダによるグループ分け（メジャー、マイナー、7th など）
- 基本的な 4 和音コード（23 種）をデフォルトで収録
- フレットボードエディタで 1〜25 フレットに対応したオリジナルコードの作成

### 曲管理
- 曲ごとにタイトル・BPM・カポ・スクロール速度・メモを設定
- 歌詞をセクション単位で管理（1 行 = 1 セクション）
- セクションに対してコードダイアグラムを任意の横位置に配置
- コード名・ダイアグラムの表示 / 非表示をセクションごとに個別設定

### 編集モード
- 歌詞入力中に Return キーで次のセクションを作成（カーソル位置でテキストを分割）
- コードエリアをタップしてコードを配置
- ドラッグでコードの横位置を微調整
- コードのダイアグラム表示・コード名表示を個別にオン / オフ

### パフォーマンスモード
- 設定した速度で自動スクロール（テレプロンプター表示）
- 手動スクロールに対応（ドラッグで位置調整 + フリックで慣性スクロール）
- コードの表示モードを切り替え（カスタム / ダイアグラムのみ / コード名のみ / 非表示）
- メトロノーム（クリック音）をオン / オフ

### フレットボードエディタ
- ギター指板を忠実に再現したビジュアルデザイン（ローズウッド・シルバーフレット・ポジションマーク）
- 横スクロールで 1〜25 フレットに対応
- 弦ごとにミュート (X)・開放弦 (O)・押弦を切り替え
- 各弦の太さと色でアコースティックギターの金属感を表現

## プロジェクト構成

```
chordify/
├── Models/
│   ├── Song.swift              # 曲モデル（BPM・カポ・メモ・表示モード）
│   ├── LyricsSection.swift     # セクション（歌詞 + コード配置リスト）
│   ├── ChordDiagram.swift      # コードダイアグラム（グローバル / 曲固有）
│   ├── ChordFingering.swift    # フィンガリングデータ
│   ├── ChordPlacement.swift    # コード配置（正規化 X 座標・表示設定）
│   ├── EffectorMemo.swift      # エフェクターメモ（セクションに紐付く）
│   └── DefaultChords.swift     # デフォルトコードのシードデータ
└── Views/
    ├── ChordBook/
    │   ├── ChordBookView.swift  # コードブック（グリッド表示・フォルダ別）
    │   └── ChordEditView.swift  # コード追加・編集フォーム
    ├── Songs/
    │   ├── SongListView.swift   # 曲一覧
    │   ├── SongDetailView.swift # 曲詳細（編集 / パフォーマンスモード）
    │   └── LyricsScrollView.swift # 自動スクロールViewModel
    └── Common/
        ├── FretBoardView.swift        # コードダイアグラム表示（Canvas）
        ├── FretBoardEditorView.swift  # コードダイアグラム編集
        ├── ChordPickerSheet.swift     # コード選択シート（グリッド）
        ├── ChordDiagramCell.swift     # コードセル（一覧用）
        └── EffectorMemoSheet.swift    # エフェクターメモシート
```

## 今後の追加予定機能

### 歌詞拡大表示
パフォーマンス中に特定のセクションの歌詞をピンチアウトやダブルタップで拡大表示する機能。演奏の要所で歌詞を大きく映したい場面に対応します。

### 音声ファイルアップロード
曲に音声ファイル（MP3・AAC など）を紐付けて、アプリ内で再生できる機能。オリジナル音源と歌詞・コードを一元管理し、コピー練習や音取りをよりスムーズに行えます。

### エフェクターメモ
セクションごとにエフェクターのセッティングをメモできる機能（データモデルは実装済み）。ドライブ量・リバーブ・ディレイなどのノブ設定をテキストで記録し、パフォーマンスモードでも確認できます。
